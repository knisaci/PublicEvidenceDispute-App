# PublicEvidenceDispute-App

Two-party public-evidence court on GenLayer.

## Steward update
Both parties commit a claim and an evidence URL before resolve.
Creator commit is set at deploy and is immutable.
Defendant commit_defense() can be called only once.
resolve() is blocked until both commits exist.
Validators fetch BOTH evidence pages.
